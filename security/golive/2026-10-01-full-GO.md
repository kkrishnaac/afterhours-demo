## Attack surface (Phase 1)

| Surface | Access | Protection |
|---|---|---|
| Pages and assets (`dist/` via `env.ASSETS`) | Public | Static; security headers from `dist/_headers`; `.html` requests 307 to clean paths; unknown paths 404 |
| `POST /api/walkthrough` | Public, anonymous (by design) | Origin allowlist, JSON only, rate limit before the body is read (5/min per IP), streamed 8 KB cap, schema allowlist, honeypot, Turnstile verified server-side, atomic duplicate check + insert, parameterised D1 |
| Any other `/api/*` or method | Public | 404 / 405, JSON body, no detail |
| Cron (every 15 min) | Not reachable over HTTP | Retries held notifications; deletes rows past 730 days |
| D1 `walkthrough_requests` | Worker binding only | No HTTP read path; people read it through the Cloudflare account (`npm run leads`) |
| Outbound | Turnstile siteverify, Resend | Fixed URLs, server-held secrets |
| Browser third party | `challenges.cloudflare.com` (last form step only). Cloudflare Web Analytics only once `CF_BEACON_TOKEN` is set | CSP lists only these origins |

Inputs: JSON body fields (`size`, `timing`, `city`, `name`, `email`, `phone`, `marketing`, `company_site`
honeypot, `turnstile`); headers `Origin`, `Content-Type`, `Content-Length`, `CF-Connecting-IP`; and
one new URL parameter since the last gate, `?city=` on the home page (client side only, matched
against the fixed city allowlist, written with `textContent`, then removed from the URL).

## UNLISTED NOTES (not findings)

- WebKit logs a `style-src-attr` CSP violation on every page load. It fires with JavaScript
  disabled and points at the `<select>` for the city: WebKit's own form-control styling, not our
  code. The select renders and works (17 options, selection verified on iPhone emulation).
  No `unsafe-inline` was added to silence it.
- The analytics setting was briefly named with Vite's public `VITE_` prefix; it is now
  `CF_BEACON_TOKEN`, read by the build config only, validated as 32 hex characters, and off
  until set. The token itself is public by design (it sits in the page), not a secret.
- The Origin check is not authentication: Turnstile is the real gate, verified server-side.
- Names may contain `<` and `"`; they are escaped in the HTML emails and never rendered on the site.
