## Attack surface (Phase 1)

- **Routes:** one public static page (`index.html`) plus hashed assets, fonts, images and
  `fonts/cormorant-600.typeface.json`. No server routes, no admin, no API.
- **Input:** the quote form (`src/quote.js`). It never leaves the browser: `submit` is
  `preventDefault`ed and nothing is fetched or stored. Pointer position drives the 3D tilt.
- **Outbound:** none. Fonts self-hosted via @fontsource; the only fetch is the same-origin
  typeface JSON.
- **Data:** none stored. No cookies, no localStorage, no analytics.

## Fixed during the gate

- **[T2] `.env` not in `.gitignore` (scan BLOCK).** No `.env` exists and none is in history, but
  the guard was missing. Added `.env`, `.env.*`, `*.pem`, `*.key` to `.gitignore`.
- **[T47] No security headers (scan CRITICAL).** GitHub Pages cannot set headers. Production
  `index.html` now carries a CSP meta (`default-src 'self'`, `script-src 'self'`, `style-src 'self'`,
  `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`) and `referrer: strict-origin-when-cross-origin`,
  injected by the `security-meta` plugin in `vite.config.js` (build only). Verified on the built
  site: 0 CSP violations, 3D hero, fonts, map and form all working.

## Adversarial pass (Phase 3)

1. Browser only: probe paths return GitHub's static 404. Nothing to log into.
2. Changing IDs: no IDs, no requests carry data.
3. Client-trusted data: the form's values are only echoed back to the same visitor (first name via
   `textContent`). No price, role or entitlement exists.
4. Hostile user: can only type into their own browser. Worst case is self-XSS, blocked by `textContent` and CSP.

**UNLISTED:** none.

## Before this becomes the real site (not blocking the demo)

- When the quote form starts sending data: server-side validation, spam protection / rate limit,
  CASL-compliant consent wording, and a privacy policy (PIPEDA). Run `build-security` Part B.
- Replace placeholder phone `(416) 555-0199` and `hello@example.com`, and remove `noindex`.
- Confirm usage rights for the Higgsfield-generated photos on the plan used (API, pay-as-you-go).
- If moved to Netlify / Vercel / Cloudflare: set CSP, `frame-ancestors 'none'`, `X-Content-Type-Options`,
  and `Permissions-Policy` as real headers.
